# 分身任務卡（空白版 v1）

> 練習用：只用測試帳號與假資料。填完後存成自己的副本，後面每個模組都會回來對照。

| 欄位 | 你的答案 |
|---|---|
| 1. 目標（一句話：這個分身幫你做什麼事） | |
| 2. 用哪些工具（只列你打算授權的，例：Claude＋Microsoft Learn 查詢、Gemini＋測試日曆） | |
| 3. 可以做（列 2–4 件） | |
| 4. 不可以做（至少 3 條） | |
| 5. 什麼時候要先問我（列 2–3 種情況） | |
| 6. 什麼時候停（列 1–2 種情況） | |

## 填寫提醒

- 「可以做」和「不可以做」都要寫得具體：寫「不可以刪除行程」比寫「不可以亂來」好。
- 「先問我」是指分身先停下來等你回覆；「停」是指分身不再繼續、把狀況告訴你。
- 工具欄只寫你現在就會授權的，之後學到新工具再回來加。
