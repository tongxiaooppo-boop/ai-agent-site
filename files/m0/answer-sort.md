# 這件事該用哪一種：參考答案

> 先自己分完再看。有些題兩種都說得通，重點是你的理由。

| 題號 | 分類 | 理由（一行） |
|---|---|---|
| 1 | 自動化 | 固定時間、固定動作，不需要判斷，照規則跑就好。 |
| 2 | 聊天 | 一次問答，人看完結果自己決定，不需要接任何工具。 |
| 3 | agent | 要讀通知、整理草稿、等人確認後再用日曆工具寫入，有判斷也有工具。 |
| 4 | 聊天 | 單純問一個操作方法，看一段說明就好。 |
| 5 | 自動化 | 每月固定、動作固定，不需要判斷。 |
| 6 | agent | 要自己決定查什麼、呼叫查詢工具、讀結果、再整理成附來源的回答。 |
| 7 | 聊天 | 發想點子，不需要工具，也不會動到任何東西。 |
| 8 | agent | 要先用日曆工具查，再依結果決定往下做還是停下來問，每一步都看上一步的結果。 |

## 怎麼分

- 只是問、答：聊天。
- 固定時間、固定步驟、不用判斷：自動化。
- 要看情況決定下一步，而且會用到工具：agent。
